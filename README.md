# 🎨 Dribbble Copy - Homepage, Sign In & Sign Up  

A simple **Dribbble-inspired** UI design project that replicates the **homepage, sign-in, and sign-up pages** using **HTML, CSS, and JavaScript**. This project is perfect for learning front-end development and UI design best practices.  

## 🌟 Features  
✅ **Homepage:** A clean and modern UI layout similar to Dribbble 🎨  
✅ **Sign In Page:** Secure login form with stylish design 🔑  
✅ **Sign Up Page:** User-friendly registration form for new accounts 📝  
✅ **Responsive Design:** Works across all devices 📱💻  
✅ **Smooth Animations:** Enhances the user experience ✨  

## 🛠️ Technologies Used  
- **HTML** – Structuring the UI  
- **CSS** – Styling and responsiveness  
- **JavaScript** – Form validation and interactive elements  

## 🚀 How to Use  
1. Clone the repository:  
   ```bash
   git clone https://github.com/Fatima-progmmer/Dribble-copy.git
   ```  
2. Open `index.html` for the homepage.  
3. Open `signin.html` and `signup.html` for authentication pages.  
4. Customize styles or scripts as needed!
